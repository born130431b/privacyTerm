## 1. 적용 범위

이 방침은 End Game의 한국 대상 Android 비공개 테스트와 그에 관한 문의에 적용합니다. 테스트는 만 14세 이상을 대상으로 하며 무료로 제공합니다. 본 문서는 해당 테스트에 적용되는 개인정보 처리방침입니다. 향후 온라인 계정·클라우드 저장·광고·결제 등 처리 범위가 바뀌면 실제 기능을 제공하기 전에 방침과 필요한 동의 절차를 갱신합니다.

이번 배포본은 기기 내 진행 저장을 이용합니다. 공개 게임 서버를 통한 계정 가입, 채팅·길드·침공, 클라우드 백업, 실제 결제 및 보상형 광고는 제공하지 않습니다. 개발자 PC의 로컬 API 테스트와 별도 Firebase 로그인 테스트는 이번 배포 서비스에 포함하지 않습니다. 개발용 기능의 메뉴나 안내가 보이더라도 실제 온라인 서비스가 연결된다는 뜻은 아닙니다.

## 3. SDK·자동 수집 장치와 외부 접속

이번 비공개 테스트는 릴리스 빌드입니다. Google Mobile Ads Unity Plugin과 UMP 연동 코드는 프로젝트에 있으나 릴리스에서 광고·UMP 요청을 차단하며 보상형 광고를 제공하지 않습니다. Firebase Authentication 패키지도 프로젝트에 있지만 로그인 테스트 화면은 배포 씬에서 제외되고 일반 게임의 로그인·진행 저장에 사용하지 않습니다. Firebase Analytics·Crashlytics를 통한 이용 분석·오류 수집 기능을 제공하지 않습니다. 광고나 로그인 기능이 활성화된 별도 버전을 이번 방침의 범위로 취급하지 않습니다.

배경 음악·효과음·포탈 이미지는 앱에 포함된 자료로 재생하며 원본 제작자나 배포 사이트로 게임 진행·재생 이력을 보내지 않습니다. 운영자가 게임 내 쿠키를 이용해 이용자를 추적하지 않습니다.

이용자가 정책·약관·출처 링크를 열면 외부 브라우저 또는 해당 사이트에 접속합니다. 이때 IP 주소, 브라우저·기기 정보, 사이트 쿠키 등은 GitHub·Google 또는 해당 사이트가 자체 정책에 따라 처리할 수 있습니다. 문의 이메일은 Gmail을 통해 수신·보관합니다. 외부 링크 방문과 이메일 전송은 이용자가 선택하며, 방문·문의하지 않아도 기본 게임을 이용할 수 있습니다.

## 4. 제3자 제공·위탁·국외 처리

운영자는 기기 내 진행·연령 구간을 광고주나 다른 이용자에게 제공하지 않으며, 해당 데이터를 처리하는 외부 게임 서버·DB·CDN 수탁자를 이번 테스트에서 사용하지 않습니다. 판매 목적의 개인정보 제공을 하지 않습니다. 법령에 따른 적법한 요구가 있으면 그 근거와 필요한 범위에 한해 처리합니다.

문의 수신에는 Google LLC의 Gmail을 이용합니다. 이메일 주소·내용·첨부 자료가 이용자의 전송 시점에 인터넷을 통해 Google의 메일 시스템으로 전달되어 문의 응대에 이용됩니다. Google 서비스는 미국을 포함한 여러 국가의 서버에서 정보를 처리할 수 있으며, Google은 [개인정보처리방침의 정보 이전 안내](https://policies.google.com/privacy#infosharing)와 [문의 경로](https://support.google.com/policies/answer/9581826)를 제공합니다. 운영자가 관리하는 문의 사본의 기간은 제2조를 따르고, 제공자 자체 기록은 해당 제공자의 정책이 적용됩니다. 기기 내 게임 데이터가 문의를 이유로 자동 첨부되지는 않습니다. 이메일을 보내지 않으면 이 문의 전송은 발생하지 않으며 기본 게임 이용에 불이익이 없습니다.

GitHub는 정책·약관의 공개 열람 경로입니다. 이용자가 링크를 열 때 해당 사이트로 직접 접속하며, 운영자가 게임 진행 DB를 GitHub로 이전하거나 보관하는 용도로 사용하지 않습니다. 이 방침은 외부 제공자의 자체 처리나 법령상 필요한 별도 국외 이전 동의를 대신하지 않습니다.

## 5. 삭제와 안전한 관리

기기 내 정보는 Android 설정의 앱 데이터 삭제 또는 앱 삭제로 삭제할 수 있습니다. 기기·운영체제가 별도 보관하는 백업은 해당 플랫폼 설정에서 관리해야 합니다. 기기 내 저장만 있는 진행을 운영자가 원격으로 복원하거나 삭제할 수는 없습니다.

문의 자료는 보유 기간 종료 또는 삭제 요청 처리 시 운영자가 관리하는 메일함·첨부 파일·별도 내려받은 사본에서 삭제하고 휴지통을 비웁니다. 문의 자료를 별도의 상시 백업으로 복제하지 않습니다. 법령상 보관이 필요한 경우 요청자에게 근거·항목·기간을 알리고 해당 목적에 한해 분리 보관한 뒤 기간 종료 시 삭제합니다. 전자 자료는 복구·재사용하지 않도록 삭제하며 종이 출력물이 있으면 분쇄합니다.

운영자는 문의 계정의 접근 권한을 담당자로 제한하고 계정 보안 기능을 이용합니다. 불필요한 인증 정보나 민감 자료를 수집하지 않고 문의 자료의 공개 저장소 등록을 금지합니다. 기기 자체의 잠금과 운영체제 보안 설정은 이용자가 관리합니다.
